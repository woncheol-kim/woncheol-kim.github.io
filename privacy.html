Privacy Policy

Last updated: October 20, 2026

Overview

This application uses rclone, an open-source command-line program, to access and manage files in Google Drive. The OAuth client ID associated with this application is used for my personal use of rclone.

Information Accessed

Depending on the permissions granted during authorization, rclone may access Google Drive file names, metadata, file contents, and other information needed to perform the operations requested by the user. Google OAuth authentication tokens are also used to authorize access.

How Information Is Used

Information accessed through the Google Drive API is used solely to perform file operations explicitly requested by the user, such as listing, copying, synchronizing, moving, or deleting files.

Storage and Sharing

Rclone runs on the user's own computer. Its configuration and authentication tokens are stored locally according to the user's configuration. File transfers are performed between the user's computer and the relevant cloud service. This personal application does not operate a server to collect or store Google Drive files or authentication tokens.

I do not collect or sell Google Drive user data through this personal application, or share it with third parties.

Data Security

Users are responsible for protecting their computers and rclone configuration files, including authentication tokens. Access to Google Drive can be revoked through the user's Google Account security settings.

Third-Party Services

Access to Google Drive is governed by Google's applicable privacy policies and terms. Rclone is open-source software maintained separately from this personal OAuth configuration.

Contact
